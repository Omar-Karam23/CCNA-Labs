# **RIP v2 Authentication – MD5**

## **1. Lab Overview**

**Objective:** Configure RIPv2 with MD5 Authentication between two routers (R1 and R2) to secure RIP routing updates.


## **2. Lab Instructions – Steps**

1. **Build the Network Topology**
    
    - Connect R1 to R2 using FastEthernet0/0.
        
    
2. **Configure Loopback Interfaces**
    
    - Assign 1.1.1.1/32 to R1.
        
    - Assign 2.2.2.2/32 to R2.
        
    
3. **Configure Physical Interfaces**
    
    - Assign IP addresses in the same subnet (10.0.0.0/24).
        
    - Ensure interfaces are enabled.
        
    
4. **Configure Key Chain**
    
    - Create a Key Chain named `OMAR`.
        
    - Configure Key 1 with authentication key `1234`.
        
5. **Configure RIPv2**
    
    - Enable RIP Version 2.
        
    - Advertise the Loopback and FastEthernet networks.
        
    
6. **Configure RIP Authentication**
    
    - Enable MD5 authentication on FastEthernet0/0 Only.
        
    - Connect the interface FastEthernet0/0 with Key Chain `OMAR`.
        
    
7. **Verify Configuration**
    
    - Check RIP neighbors and learned routes.
        
    - Test end-to-end connectivity.


## **3. Devices Configuration**

### **R1 Configuration**

**Global Configuration Mode**

```
R1# configure terminal
R1(config)# hostname R1
R1(config)# key chain OMAR
R1(config-keychain)# key 1
R1(config-keychain-key)# key-string 1234
R1(config-keychain-key)# exit
R1(config-keychain)# exit
```

**Interface Configuration Mode – Loopback1**

```
R1(config)# interface Loopback1
R1(config-if)# ip address 1.1.1.1 255.255.255.255
R1(config-if)# exit
```

**Interface Configuration Mode – FastEthernet0/0**

```
R1(config)# interface FastEthernet0/0
R1(config-if)# ip address 10.0.0.1 255.255.255.0
R1(config-if)# ip rip authentication mode md5
R1(config-if)# ip rip authentication key-chain OMAR
R1(config-if)# no shutdown
R1(config-if)# exit
```

**RIP Configuration Mode**

```
R1(config)# router rip
R1(config-router)# version 2
R1(config-router)# network 1.0.0.0
R1(config-router)# network 10.0.0.0
R1(config-router)# end
```

## **4. Checks and Expected Outputs**

### **Check 1: Verify Interface Status**

**On both routers:**

```
show ip interface brief
```

Expected output:

```
Interface              IP-Address      Status     Protocol
Loopback1              1.1.1.1         up         up
FastEthernet0/0        10.0.0.1        up         up
```

On R2 the corresponding addresses should be `2.2.2.2` and `10.0.0.2`.

### **Check 2: Verify Key Chain**

```
show key chain
```

Expected output (key details):

```
Key-chain OMAR:
    key 1 -- text "1234"
```

### **Check 3: Verify RIP Configuration**

```
show ip protocols
```

Expected:

- Routing Protocol: RIP
    
- Sending updates every 30 seconds.
    
- Default version: send and receive version 2.
    
- Routing for Networks: 1.0.0.0 and 10.0.0.0 on R1.
    
- Routing for Networks: 2.0.0.0 and 10.0.0.0 on R2.
    

### **Check 4: Verify RIP Authentication**

**On both routers:**

```
show ip rip database
```

And:

```
show running-config interface FastEthernet0/0
```

Expected configuration:

```
ip rip authentication mode md5
ip rip authentication key-chain OMAR
```
