**Lab Name:** EIGRP Basic Configuration

**Objective:**

Configure EIGRP (Enhanced Interior Gateway Routing Protocol) between two Cisco routers to establish neighbor adjacency and exchange routing information.


**Main Objectives:**

- Configure IP addressing on router interfaces.
    
- Enable EIGRP on both routers.
    
- Establish EIGRP neighbor adjacency.
    
- Advertise Loopback networks.
    
- Exchange routing information.
    
- Verify end-to-end connectivity.
    

# **2. Lab Instructions – Steps**

### **Step 1: Configure R1 Interfaces**

- Configure Loopback1 with `1.1.1.1/32`.
    
- Configure FastEthernet0/0 with `10.0.0.1/24`.
    
- Ensure the physical interface is enabled.
    

### **Step 2: Configure R2 Interfaces**

- Configure Loopback1 with `2.2.2.2/32`.
    
- Configure FastEthernet1/0 with `10.0.0.2/24`.
    
- Ensure the physical interface is enabled.
    

### **Step 3: Configure EIGRP**

On both routers:

- Enable EIGRP using AS number `100`.
    
- Advertise the Loopback network.
    
- Advertise the directly connected network `10.0.0.0/24`.
    

### **Step 4: Establish Neighbor Adjacency**

EIGRP routers should discover each other through their shared Ethernet network.

The two routers must use the same EIGRP AS number and have compatible EIGRP parameters.

### **Step 5: Verify Routing Information**

Check whether each router has learned the remote Loopback network through EIGRP.

# **3. Devices Configuration**

## **R1 Configuration**

```

! R1

! Global Configuration
configure terminal

! Loopback Interface
interface Loopback1
 ip address 1.1.1.1 255.255.255.255
 exit

! Physical Interface
interface FastEthernet0/0
 ip address 10.0.0.1 255.255.255.0
 no shutdown
 exit

! EIGRP Configuration
router eigrp 100
 network 1.1.1.1 0.0.0.0
 network 10.0.0.0 0.0.0.255
 exit

end
```

## **R2 Configuration**

```

! R2

! Global Configuration
configure terminal

! Loopback Interface
interface Loopback1
 ip address 2.2.2.2 255.255.255.255
 exit

! Physical Interface
interface FastEthernet1/0
 ip address 10.0.0.2 255.255.255.0
 no shutdown
 exit

! EIGRP Configuration
router eigrp 100
 network 2.2.2.2 0.0.0.0
 network 10.0.0.0 0.0.0.255
 exit

end
```

# **4. Checks and Expected Outputs**

### **4.1 Check EIGRP Neighbors**

On both routers:

```
show ip eigrp neighbors
```

Expected output on R1:

```
H   Address       Interface
0   10.0.0.2      Fa0/0
```

Expected output on R2:

```
H   Address       Interface
0   10.0.0.1      Fa1/0
```

Expected: Neighbor Established

### **4.2 Check EIGRP Routing Table**

On R1:

```
show ip route eigrp
```

Expected:

```
Gateway of last resort is not set

      2.0.0.0/32 is subnetted, 1 subnets
D        2.2.2.2 [90/156160] via 10.0.0.2, 00:13:12, FastEthernet0/0
R1#

```

On R2:

```
show ip route eigrp
```

Expected:

```
D    1.1.1.1/32 [90/...] via 10.0.0.1
```

**Important:**

- `D` = EIGRP Route.
    
- `90` = Administrative Distance of Internal EIGRP.
    
- The second value represents the EIGRP Metric.
    
- `via` identifies the next-hop router.
    

### **4.3 Check EIGRP Protocol**

On both routers:

```
show ip protocols
```

Expected important information:

```
Routing Protocol is "eigrp 100"
Automatic Summarization: disabled
Maximum path: 4
Routing for Networks:
  1.1.1.1/32
  10.0.0.0/24
```

The advertised Loopback network will differ between R1 and R2.

### **4.5 Check EIGRP Topology Table**

On R1:

```
show ip eigrp topology
```

Expected important entry:

```
P 2.2.2.2/32, 1 successors
    via 10.0.0.2
```

On R2:

```
show ip eigrp topology
```

Expected important entry:

```
P 1.1.1.1/32, 1 successors
    via 10.0.0.1
```

`P` means Passive.
