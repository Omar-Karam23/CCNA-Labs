# **OSPF Cost – Traffic Engineering**

## **1. Lab Overview**

### **Objective**

The objective of this lab is to understand how **OSPF Cost** influences route selection and how network administrators can use manual cost configuration to control traffic paths within an OSPF routing domain.

In this lab we use the `ip ospf cost` command to manipulate the OSPF metric on router interfaces and influence the path selected by OSPF.

## **2. Lab Instructions – Steps**

### **Step 1: Configure IP Addressing**

Configure the IP addresses on all router interfaces according to the topology.

Configure Loopback1 on R2 with the address `2.2.2.2/32`.

**Network Topology:**

|Device|Interface|IP Address|Connected To|
|---|---|---|---|
|R1|Fa0/0|10.0.0.1/30|R2|
|R1|Fa1/0|11.0.0.1/30|R3|
|R2|Fa0/0|10.0.0.2/30|R1|
|R2|Fa1/0|12.0.0.2/30|R3|
|R2|Lo1|2.2.2.2/32|Loopback|
|R3|Fa0/0|12.0.0.1/30|R2|
|R3|Fa1/0|11.0.0.2/30|R1|

### **Step 2: Enable OSPF**

Enable OSPF Process ID 1 on all participating interfaces.

All interfaces belong to Area 0.

### **Step 3: Configure OSPF Cost on R1**

Manually modify the OSPF cost on R1:

- Fa0/0 → Cost 30
    
- Fa1/0 → Cost 1
    

This creates different path costs toward R2.

### **Step 4: Verify OSPF Adjacencies**

Verify that all routers establish OSPF neighbor relationships.

### **Step 5: Verify Route Selection**

Check the routing table on R1 and observe the selected path toward `2.2.2.2/32`.

OSPF should select the path through R3 because its cumulative cost is lower.

### **Step 6: Test Connectivity**

Use ping and traceroute to verify connectivity between R1 and R2 Loopback1.

## **3. Devices Configuration**

### **R1 Configuration**

```
! Global Configuration Mode
hostname R1

! Interface Configuration Mode
interface FastEthernet0/0
 ip address 10.0.0.1 255.255.255.252
 ip ospf 1 area 0
 ip ospf cost 30
 no shutdown
!
interface FastEthernet1/0
 ip address 11.0.0.1 255.255.255.252
 ip ospf 1 area 0
 ip ospf cost 1
 no shutdown
```

### **R2 Configuration**

```
! Global Configuration Mode
hostname R2

! Interface Configuration Mode
interface Loopback1
 ip address 2.2.2.2 255.255.255.255
 ip ospf 1 area 0
!
interface FastEthernet0/0
 ip address 10.0.0.2 255.255.255.252
 ip ospf 1 area 0
 no shutdown
!
interface FastEthernet1/0
 ip address 12.0.0.2 255.255.255.252
 ip ospf 1 area 0
 no shutdown
```

### **R3 Configuration**

```
! Global Configuration Mode
hostname R3

! Interface Configuration Mode
interface FastEthernet0/0
 ip address 12.0.0.1 255.255.255.252
 ip ospf 1 area 0
 no shutdown
!
interface FastEthernet1/0
 ip address 11.0.0.2 255.255.255.252
 ip ospf 1 area 0
 no shutdown
```
