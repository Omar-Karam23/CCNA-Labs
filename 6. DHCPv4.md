## **1. Lab Overview**

### **Objective**

The objective of this lab is to configure a Cisco Router as a DHCPv4 Server to dynamically assign IPv4 addresses to network devices and provide the required network parameters.

The lab also demonstrates how to configure a DHCP Reservation (Manual Binding) to assign a specific IP address to a particular device using its DHCP Client-Identifier.


### **DHCP DORA Process**

## **DHCP DORA**

1. **Discover**
    
    Client broadcasts a DHCP Discover message to find DHCP servers.
    
2. **Offer**
    
    DHCP Server offers an available IP address to the client.
    
3. **Request**
    
    Client requests the offered IP address.
    
4. **Acknowledgment**
    
    DHCP Server confirms the assignment and provides the network configuration.

## **2. Lab Instructions – Steps**

### **Step 1 – Configure the DHCP Server Interface**

Configure the router interface with a static IP address.

```
DHCP> enable
DHCP# configure terminal
DHCP(config)# service dhcp
DHCP(config)# interface FastEthernet0/0
DHCP(config-if)# ip address 192.168.1.1 255.255.255.0
DHCP(config-if)# no shutdown
```

**Purpose:** The DHCP server must have a statically configured IP address to act as the default gateway for the clients.

### **Step 2 – Configure Excluded IP Addresses**

```
DHCP(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.20
```

**Purpose:** Prevent the DHCP server from assigning addresses between 192.168.1.1 and 192.168.1.20.

### **Step 3 – Create DHCP Pool**

```
DHCP(config)# ip dhcp pool LAN1
DHCP(dhcp-config)# network 192.168.1.0 255.255.255.0
DHCP(dhcp-config)# default-router 192.168.1.1
DHCP(dhcp-config)# dns-server 8.8.8.8
DHCP(dhcp-config)# lease 0 6
```

### **Step 4 – Configure a DHCP Pool for a Specific Client**

```
DHCP(config)# ip dhcp pool SERVERD_IPs
DHCP(dhcp-config)# 192.168.1.27 255.255.255.0
DHCP(dhcp-config)# client-identifier 0063.6973.636f.2d63.6130.342e.6661.6439.2e30.3030.302d.4661.302f.30
DHCP(dhcp-config)# default-router 192.168.1.1
DHCP(dhcp-config)# dns-server 8.8.8.8
```

**Purpose:** Create a DHCP pool that identifies a specific client using its DHCP Client Identifier.


### **Step 5 – Configure DHCP Clients**

On the CLINET router:

```
CLINET> enable
CLINET# configure terminal
CLINET(config)# interface FastEthernet0/0
CLINET(config-if)# ip address dhcp
CLINET(config-if)# no shutdown
```

On the Printer :

```
Printer> enable
Printer# configure terminal
Printer(config)# interface FastEthernet0/0
Printer(config-if)# ip address dhcp
Printer(config-if)# no shutdown
```
